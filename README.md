# GetVerse

Application pour projeter des versets bibliques pendant le culte.
Disponible uniquement pour Windows 10 et 11.

## Installation

Double-cliquez sur **GetVerse Setup 1.0.0.exe** et suivez les étapes.
Un raccourci GetVerse est créé sur le bureau. Pour désinstaller, utilisez
« Désinstaller GetVerse » dans le menu Démarrer.

## Utilisation

| Touche | Action |
| --- | --- |
| `Tab` / `Entrée` | Valider le livre, puis le chapitre ; `Entrée` projette quand le verset est saisi |
| `↑` `↓` | Choisir parmi les suggestions de livres |
| `←` `→` | Verset précédent / suivant (après une projection) |
| `Page ↑` `Page ↓` | Précédent / suivant à tout moment |
| `Échap` | Écran vide |
| `F2` | Changer de version (Louis Segond 1910 / Bible du Semeur) |

Exemples de saisie : `gn 1 1`, `jean 3:16`, `jn 3:16-18`, puis `5` (verset 5 du même chapitre) ou `2:5`.

## Logo de l'église

Dans le panneau « Logo de l'église », choisissez votre image : elle s'affiche en rond, au centre,
au-dessus du verset. Un curseur règle sa taille.

## Lancer avec OBS, Teams, Google Meet, Zoom…

Dans le panneau « Lancer avec », cliquez sur le bouton et choisissez :

- **OBS Studio** : GetVerse ouvre OBS et y ajoute l'affichage des versets dans la scène en cours.
- **OBS + caméra virtuelle** : idem, avec la caméra virtuelle d'OBS démarrée. Dans Teams, Meet ou Zoom,
  choisissez la caméra « OBS Virtual Camera ».
- **Microsoft Teams, Google Meet, Zoom, Autre application** : GetVerse ouvre l'application et une fenêtre
  « GetVerse - Partage ». Dans la réunion, partagez cette fenêtre.

Avant de lancer avec OBS, choisissez le rendu : plein écran, texte seul (fond transparent) ou bandeau.
OBS Studio doit être installé. GetVerse doit rester ouvert pendant le direct.
